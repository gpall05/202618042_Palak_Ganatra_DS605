#  BookScraper

A Python project that demonstrates web scraping, data preprocessing, visualization, and basic data analysis using the **BooksToScrape** website.

##  Features

- Scraped book data using **Scrapy**
- Cleaned and preprocessed the dataset with **Pandas**
- Performed feature engineering
- Created data visualizations using **Matplotlib**
- Generated insights from the dataset

## Tech Stack

- Python
- Scrapy
- Pandas
- Matplotlib
- WordCloud
- Jupyter Notebook

##  Project Workflow

Web Scraping → Data Cleaning → Feature Engineering → Visualization → Insights

##  Files

- `books.py` – Web scraper
- `preprocess.py` – Data cleaning & feature engineering
- `visualize.py` – Data visualization
- `books.csv` – Raw dataset
- `books_cleaned.csv` – Processed dataset
- `BookScraper_Project.ipynb` – Complete workflow
