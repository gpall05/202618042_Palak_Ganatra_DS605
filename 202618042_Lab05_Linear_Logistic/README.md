# DS605 Lab 05 — Linear and Logistic Regression

## Overview

This project implements **Linear Regression** and **Logistic Regression** on the **UCI Garment Worker Productivity** dataset.

The objective is to:

* Build regression and classification models using **Scikit-learn**
* Implement the same models from scratch using **NumPy and Pandas**
* Apply data preprocessing and feature engineering
* Compare predictive performance and execution time
* Optimize the manual implementations for better computational efficiency

---

## Dataset

**Dataset:** Garment Worker Productivity

The dataset contains information related to garment production, including:

* Date
* Quarter
* Department
* Day
* Team
* Targeted productivity
* Standard Minute Value (SMV)
* Work in Progress (WIP)
* Overtime
* Incentive
* Idle time
* Idle workers
* Number of style changes
* Number of workers
* Actual productivity

The dataset used in this project contains **1,197 rows and 15 columns**.
